# Small-Office-Network-with-DHCP-DNS-and-File-Server
A Cisco Packet Tracer project demonstrating the design and implementation of a Small Office Network with Router and Switch configuration, DHCP for automatic IP allocation, DNS for hostname resolution, and a centralized File Server. The project includes end-to-end connectivity testing and basic network services for a small office environment.


# Small Office Network with DHCP, DNS & File Server

## 📌 Overview

This project demonstrates the design and implementation of a Small Office Network using Cisco Packet Tracer. It includes Router and Switch configuration, DHCP for automatic IP address allocation, DNS for hostname resolution, and a centralized File Server.

---

## 🎯 Objectives

- Configure Router
- Configure Layer 2 Switch
- Configure DHCP Server
- Configure DNS Server
- Configure File Server
- Verify network connectivity

---

## 🖥️ Devices Used

- Cisco 1941 Router
- Cisco 2960 Switch
- 1 Server
- 4 PCs
